# Icons used by these docs

Official Microsoft icons, copied unmodified and renamed to stable kebab-case keys. Diagrams reference them with `iconKey=<key>` (inlined by `embed-icons.py --icons-dir docs/assets/icons`); Markdown references them with `<img src="./assets/icons/<key>.svg">`.

|---|---|---|
| Microsoft Fabric icons (`@fabric-msft/svg-icons` v6.1.0) | [Microsoft Fabric icons](https://learn.microsoft.com/en-us/fabric/fundamentals/icons) | Permitted in architecture diagrams, training and documentation; don't crop, flip, rotate or distort; keep the product name near the icon. |
| Azure Architecture Icons V24 + Microsoft Entra icons | [Azure icons](https://learn.microsoft.com/en-us/azure/architecture/icons/) | Same terms. Microsoft reserves all other rights. |
